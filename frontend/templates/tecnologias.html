Informações do sistema

Tecnologias

Conheça as tecnologias utilizadas no desenvolvimento de aplicações web e sistemas de gerenciamento.

Flask

Definição

Flask é um framework web desenvolvido em Python, utilizado para criar sites, sistemas web e APIs.

Características

  • Leve e flexível.
  • Desenvolvido em Python.
  • Possui sistema de rotas.
  • Permite integração com HTML e CSS.

Vantagens

  • Fácil aprendizado.
  • Facilita o desenvolvimento web.
  • Permite personalizar a estrutura do sistema.
  • Possui diversas extensões.

SQLite

Definição

SQLite é um banco de dados relacional que guarda tudo em um único arquivo, sem precisar de um servidor de banco de dados. É o banco usado hoje pelo Pacific Blue, acessado direto pelo módulo sqlite3 do Python.

Características

  • Já vem instalado junto com o Python.
  • Todos os dados ficam no arquivo pacific_blue.db.
  • Suporta transações: ou grava tudo, ou não grava nada.
  • Faz as validações do banco, como referência única e estoque nunca negativo.

Vantagens

  • Não exige instalação nem configuração de servidor.
  • O backup é copiar o arquivo do banco.
  • Os dados continuam salvos mesmo se o programa fechar de repente.
  • Suficiente para o escopo deste projeto.

SQLAlchemy

Definição

SQLAlchemy é uma biblioteca Python utilizada para trabalhar com bancos de dados relacionais.

No Pacific Blue: ainda não é utilizado. O sistema acessa o SQLite diretamente, e o SQLAlchemy é um próximo passo previsto.

Características

  • Permite comunicação com bancos de dados.
  • Possui suporte a ORM.
  • Permite criar consultas utilizando Python.
  • Suporta diferentes bancos de dados.

Vantagens

  • Facilita a manipulação de dados.
  • Organiza o código do projeto.
  • Reduz a necessidade de escrever SQL manualmente.
  • Facilita operações de cadastro, consulta, alteração e exclusão.
