Informações do sistema

Tecnologias

Conheça as tecnologias utilizadas no desenvolvimento de aplicações web e sistemas de gerenciamento.

Flask

Definição

Flask é um framework web desenvolvido em Python, utilizado para criar sites, sistemas web e APIs.

Características

  • Leve e flexível.
  • Desenvolvido em Python.
  • Possui sistema de rotas.
  • Permite integração com HTML e CSS.

Vantagens

  • Fácil aprendizado.
  • Facilita o desenvolvimento web.
  • Permite personalizar a estrutura do sistema.
  • Possui diversas extensões.

SQLAlchemy

Definição

SQLAlchemy é uma biblioteca Python utilizada para trabalhar com bancos de dados relacionais.

Características

  • Permite comunicação com bancos de dados.
  • Possui suporte a ORM.
  • Permite criar consultas utilizando Python.
  • Suporta diferentes bancos de dados.

Vantagens

  • Facilita a manipulação de dados.
  • Organiza o código do projeto.
  • Reduz a necessidade de escrever SQL manualmente.
  • Facilita operações de cadastro, consulta, alteração e exclusão.
