PACIFIC BLUE — Sistema de Gestão de Estoque

Melhorias desta versão:
- Interface renovada com identidade visual azul-marinho e azul.
- Layout responsivo para desktop e celular.
- Dashboard com cartões mais claros, atalhos de entrada/saída e alertas de estoque mínimo.
- Indicadores visuais de estoque baixo, disponibilidade e status de produção/lotes.
- Tabelas, filtros, formulários e navegação com melhor legibilidade.
- Telas e rotas existentes preservadas.

Como executar:
1. Instale Python 3.10 ou superior.
2. No terminal, dentro desta pasta, execute: pip install -r requirements.txt
3. Execute: python main.py
4. Abra: http://127.0.0.1:9000

Observações importantes:
- Os dados continuam armazenados nas listas de dados.py, como na versão original; portanto, cadastros feitos em execução não persistem após reiniciar o programa.
- Este projeto ainda é uma versão de demonstração. Antes de uso real em produção, configure uma chave secreta por variável de ambiente, desative debug e implemente persistência em banco de dados e senhas com hash.

ESTRUTURA
---------
main.py                -> registra os blueprints (LIGA O SITE)
dados.py               -> listas de dicionários em memória
                         (sem banco de dados; os dados somem ao reiniciar) (GUARDA OS DADOS)
datas.py               -> funções simples para data atual e dias no local (CUIDA DAS DATAS)
controller/             -> um blueprint por área do sistema (FAZ AS COISAS)
templates/              -> páginas HTML com Jinja (MOSTRA AS TELAS)
static/css/estilo.css   -> CSS próprio, usando flexbox, bordas e formulários (DEIXA BONITO)

FUNCIONALIDADES
----------------
- Login e logout
- Cadastro de novas contas
- Recuperação de senha usando usuário + e-mail cadastrado
- Alteração de senha para o usuário logado
- Cadastro e consulta de produtos
- Cadastro e consulta de clientes
- Movimentação de estoque por Entrada, Saída e Ajuste
- Motivos de movimentação separados por tipo
- Controle simples para não deixar a saída ultrapassar o estoque
- Cadastro e conversão de lotes de lavanderia
- Ordens de produção com processo, local, data, dias no local e fluxo
- Mudança de local e registro no fluxo da ordem
- Relatórios de estoque, movimentações, estoque mínimo e lotes
- Histórico de movimentações
