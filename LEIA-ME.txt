PACIFIC BLUE - Sistema de Gestão de Estoque
=============================================

COMO RODAR
----------
1. Instale o Flask (se ainda não tiver):
   pip install flask

2. Dentro da pasta "pacific_blue", rode:
   python main.py

3. Acesse no navegador:
   http://localhost:9000

ESTRUTURA
---------
main.py                -> registra os blueprints (LIGA O SITE)
dados.py               -> listas de dicionários em memória
                         (sem banco de dados; os dados somem ao reiniciar) (GUARDA OS DADOS)
datas.py               -> funções simples para data atual e dias no local (CUIDA DAS DATAS)
controller/             -> um blueprint por área do sistema (FAZ AS COISAS)
templates/              -> páginas HTML com Jinja (MOSTRA AS TELAS)
static/css/estilo.css   -> CSS próprio, usando flexbox, bordas e formulários (DEIXA BONITO)

FUNCIONALIDADES
----------------
- Login e logout
- Cadastro de novas contas
- Recuperação de senha usando usuário + e-mail cadastrado
- Alteração de senha para o usuário logado
- Cadastro e consulta de produtos
- Cadastro e consulta de clientes
- Movimentação de estoque por Entrada, Saída e Ajuste
- Motivos de movimentação separados por tipo
- Controle simples para não deixar a saída ultrapassar o estoque
- Cadastro e conversão de lotes de lavanderia
- Ordens de produção com processo, local, data, dias no local e fluxo
- Mudança de local e registro no fluxo da ordem
- Relatórios de estoque, movimentações, estoque mínimo e lotes
- Histórico de movimentações
